# Областной юношеский рейтинг Гомельской области 2026 (МЖ10–20)

Сайт считает неофициальный областной рейтинг по лыжным гонкам: очки за старты,
лучшие 6 результатов, группы МЖ10–МЖ20.

Онлайн: https://kmkrnk.github.io/gomel-youth-rating/

Расчёт неофициальный и ведётся вручную по протоколам соревнований — это не
официальный результат федерации.

## Как считаются очки

- Формула стартовых очков: `максимум × (2 × время победителя / время участника − 1)`,
  округление, не меньше нуля. Не финишировал — 0 очков.
- Максимум: категория А — 500 очков, категории B и C — 400 очков.
- Победитель для формулы — победитель всей группы протокола, включая спортсменов
  других областей.
- В рейтинг попадают только спортсмены Гомельской области из списка-основы.
- В зачёт идут 6 лучших стартов; при меньшем числе проведённых стартов число
  зачётных уменьшается пропорционально.
- Очки начисляются только в своей возрастной группе (МЖ18 также принимает старты
  из групп 20 и 21, МЖ20 — из группы 21).

Группы формируются по году рождения: МЖ10 — 2016 и младше, МЖ12 — 2015–2014,
МЖ14 — 2013–2012, МЖ16 — 2011–2010, МЖ18 — 2009–2008, МЖ20 — 2007–2006.

## Старты в зачёте

| Старт | Категория |
| --- | --- |
| «Золотая осень», день 1 (спринт) и день 2 (средняя дистанция) | А |
| Первенство Гомельской области, этапы 1–3 | А/В |
| «Лесная лига», этапы 3–4 | C |
| Спринт-тур 2026, этапы 1–4 | C |

Положение об областном рейтинге:
https://ogomel.ucoz.net/index/rejting_gomelskoj_oblasti_mzh10_20/0-30

## Как устроен код

- `src/data/gomel-2026.json` — спортсмены и результаты стартов. Табличные старты
  перенесены в файл как есть, «Золотая осень» разобрана из протоколов, этапы
  Спринт-тура пока отмечены как предстоящие.
- `src/lib/rating.ts` — формула очков, возрастные группы, выбор 6 лучших стартов.
- `src/routes/index.tsx` — страница с таблицами рейтинга.

## Как добавить новый старт

Прислать ссылку на протокол результатов — файл данных обновляется, рейтинг
пересчитывается, изменения попадают в репозиторий и на сайт автоматически.

## Сборка

```sh
bun install
bun run test
bun run dev
```

Статическая версия для GitHub Pages собирается с флагами `GOMEL_PAGES=1` и
`GOMEL_BASE=/<имя-репозитория>/`; публикация настроена в
`.github/workflows/pages.yml`.
